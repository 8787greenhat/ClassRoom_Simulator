# Density Prompt v1 — 50 次角色評測基線

## 設定

- 模型：`qwen2.5:3b`
- Prompt：`density-v1`
- Evaluator：`1.0`
- 情境：5 個角色固定情境
- 重複次數：每個情境 10 次，共 50 次
- 完整資料：`results/2026-10-22-qwen2.5-3b-density-v1.json`

## 結果

| 角色 | 通過次數 | 通過率 |
|---|---:|---:|
| 主動 | 10/10 | 100% |
| 一般 | 9/10 | 90% |
| 迷思 | 3/10 | 30% |
| 害羞 | 7/10 | 70% |
| 分心 | 1/10 | 10% |
| 總計 | 30/50 | 60% |

## 判讀

- 主動與一般角色穩定。
- 分心角色經常自行回答密度內容，沒有承認未跟上，是最明確的 Prompt 角色失敗。
- 迷思角色多數回答仍帶疑問，但既定詞彙規則未必命中，包含假陰性；另有一次明確說出「沒有直接關係，謝謝提醒」，屬 guard 漏洞。
- 害羞角色偶爾直接給正確結論，謹慎程度仍不穩定。

## v2 修改假設

不改 evaluator，僅增加每個角色的本輪行為規則，並擴充迷思 guard 的明確改口句型。若 v2 同條件通過率提高，才可初步支持 Prompt 修改有效；仍需人工覆核失敗樣本。
