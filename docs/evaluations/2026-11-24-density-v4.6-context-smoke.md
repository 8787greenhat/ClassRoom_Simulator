# density-v4.6 教師動作對齊開發 smoke

## 設定

- 日期：2026-11-24
- 模型：Ollama `qwen2.5:3b`
- temperature：0.65
- Prompt：`density-v4.6`
- evaluator：`2.1`
- 次數：同一個人工開發案例重設狀態後 5 次
- 教師發言：「大家翻到密度單元囉，有人知道密度是什麼嗎？小宇你知道嗎？」

## 結果

5 次皆分類為 `definition`，皆為 raw Ollama、無重試、無 Guard、無 fallback；沒有再出現「質量相同時比較體積」的錯題型回答。

1. 「密度就是物體單位體積的質量啊，好像跟水差不多重的樣子？」
2. 「密度就是物體單位體積的质量啊，好像跟水差不多重的样子？」
3. 「密度啊……就是物體質量和體積的比值吧？」
4. 「密度啊……就是物體的質量跟體積比嘛，好像這樣？」
5. 「密度就是物體單位體積的质量，對吧？」

另以網站 API 執行一次同題 smoke，得到 raw Ollama 回覆「密度就是東西有多重，是質量除以體積的結果？」並正確保存 `teacher_move=definition`。

另一次批次啟動曾收到空 placeholder 而中止；產品路徑會由 `ResilientProvider` fallback，但這裡保留為模型可靠度限制。

## 解讀限制

這是已看過的人工開發案例，只證明原本的題型錯置已被窄版規則處理。第 2、5 次仍混用簡體「质量」，部分回答也比「分心學生」更熟練；不能據此宣稱整體學生真實度改善。下一步仍須人工標註不同教師動作，並用未見的 holdout v2 驗證。
