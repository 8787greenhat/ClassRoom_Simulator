# 決策紀錄

## ADR-001：先聚焦國中自然科「密度」

- 日期：2026-10-22
- 狀態：已採用
- 決定：第一階段只完整支援密度單元，不開放任意科目承諾。
- 理由：角色迷思、教材邊界與測試答案才能明確，符合教授建議的小範圍精準驗證。

## ADR-002：Prompt baseline 先於 RAG

- 日期：2026-10-22
- 狀態：已採用
- 決定：先建立 Prompt、角色狀態與可重複評測，再加入 RAG。
- 理由：可先分離角色模擬問題與檢索問題，控制開發量並形成比較基線。

## ADR-003：本地 Ollama 搭配 deterministic fallback

- 日期：2026-10-22
- 狀態：已採用
- 決定：開發預設模型為 Ollama `qwen2.5:3b`；服務不可用時用 mock，測試不依賴模型或網路。
- 代價：mock 只能驗證流程與規則，不能代表模型品質。

## ADR-004：迷思是有強度的 session 狀態

- 日期：2026-10-22
- 狀態：已採用
- 決定：迷思強度為 0–3；有概念證據加理解檢核時，每輪最多下降一級。
- 理由：避免 LLM 投人所好，也讓變化可記錄及測試。

## ADR-005：研究主張必須來自重複評測

- 日期：2026-10-22
- 狀態：已採用
- 決定：單次示範只用於除錯；角色品質與 AI 評分可信度必須用版本化情境、多次執行與統計摘要佐證。
- 理由：模型輸出具有隨機性，個別成功案例不能支持研究結論。
